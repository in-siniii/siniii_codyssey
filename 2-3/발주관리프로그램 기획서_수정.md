# 매장 재고·발주 관리 페이지

## 대상 사용자
- 소규모 식당에서 재고를 확인하고 식재료와 공산품 발주를 맡는 주방 담당자 (사장, 점장, 주방 직원)
- 컴퓨터와 휴대폰 중 편한 기기로 사용합니다.


## 사용 목적
- 가게에 있는 식재료와 공산품(휴지, 물티슈, 냅킨, 포장용품 등)의 남은 수량을 한눈에 확인합니다.
- 발주 전에 품목의 남은 수량을 확인하고 수정합니다.
- 수량이 부족한 품목을 "발주 필요 목록"으로 자동으로 모아 보여 줘서 주문을 빠뜨리지 않게 합니다.
- 부족하지 않은 품목도 필요하면 발주 목록에 직접 추가할 수 있습니다.
- 발주를 완료하면 재고 수량이 자동으로 바뀌어서, 물건이 들어올 때마다 따로 고치지 않아도 됩니다.
- 누가, 언제, 어느 거래처에 무엇을 발주했는지 특이사항·메모와 함께 기록으로 남기고, 월별로 다시 볼 수 있습니다.


## 화면 구성과 동작
- **용어**
  - 품목: 관리하는 물건 하나하나입니다. 식재료와 공산품을 모두 포함합니다. (예: 양파, 계란, 물티슈)
  - 품목명: 품목의 이름입니다.
  - 분류: 품목을 묶는 종류입니다. (예: 채소, 육류, 공산품)
  - 묶음 단위 / 낱개 단위: 수량을 세는 단위입니다. 묶음 단위는 쓰지 않을 수도 있습니다. (예: 계란 - 묶음 단위 "판", 낱개 단위 "개")
  - 묶음당 낱개 수: 묶음 하나에 들어 있는 낱개의 수입니다. (예: 1판 = 30개)
  - 전체 낱개 수: 묶음 수량 × 묶음당 낱개 수 + 낱개 수량 (예: 1판 30개일 때 2판 5개 → 총 65개)
  - 필요 수량: 현재 수량이 이 값보다 적어지면 발주가 필요하다고 봅니다. 품목마다 정하고 고칠 수 있습니다. 묶음 단위를 쓰는 품목은 묶음과 낱개로 나눠 입력하고, 전체 낱개 수로 계산합니다.
  - 발주 수량: 이번에 주문할 양입니다. "필요 수량 - 현재 수량"으로 자동 계산되고, 직접 고칠 수 있습니다.
  - 특이사항: 발주할 때 품목마다 남기는 짧은 메모입니다. (예: 깨진 것 교환 요청)
  - 메모: 발주 한 건 전체에 남기는 메모입니다. (예: 다음 주 화요일 오전 배송 요청)

- **공통**
  - 컴퓨터와 휴대폰 화면 크기에 맞춰 보입니다. 화면 폭 800px 이하에서는 표 대신 카드 형태로 바뀌고, 480px 이하에서는 휴대폰에 맞게 글자와 버튼 배치가 바뀝니다.
  - 휴대폰에서도 글자가 겹치거나 화면 밖으로 나가지 않고, 버튼은 손가락으로 누르기 쉬운 크기로 보입니다.
  - 모든 수량 입력칸에는 숫자만 들어갑니다. 앞자리에 0을 쓰면 자동으로 지워집니다. (예: 007 → 7, "0" 하나와 0.5 같은 소수는 그대로)
  - kg처럼 소수가 필요한 낱개 수량 칸은 소수점을 하나까지 쓸 수 있고, 묶음 수량과 묶음당 낱개 수는 정수만 쓸 수 있습니다.
  - 작업이 끝나면 화면 아래에 짧은 안내(토스트)가 잠깐 나타났다 사라집니다.
  - 모든 드롭다운(분류, 거래처, 묶음 단위, 낱개 단위, 발주자, 월 선택)은 같은 모양입니다. 누르면 아래로 목록이 열리고, 고른 항목은 초록색 굵은 글씨로 표시되며, 바깥을 누르거나 Esc를 누르면 닫힙니다.

- **상단 (제목과 메뉴)**
  - 첫째 줄에 제목 "매장 재고·발주 관리"와 안내 문구 "재고를 확인하고 필요한 품목을 발주하세요."가 있습니다.
  - 제목의 "매장" 부분을 누르면 입력칸으로 바뀌어 가게 이름으로 바꿀 수 있습니다. (예: 행복분식 재고·발주 관리)
    - [확인] 또는 Enter로 바꾸고, [취소] 또는 Esc로 원래대로 돌아갑니다.
    - 최대 12글자까지 쓸 수 있고, 비우고 확인하면 "매장"으로 돌아갑니다.
    - 바꾼 이름은 바로 저장되고, 브라우저 탭 제목도 함께 바뀝니다.
  - 둘째 줄 오른쪽에 메뉴 버튼 4개와 회색 [저장] 버튼이 있습니다. 메뉴와 [저장] 사이는 메뉴끼리의 간격보다 넓게 떨어져 있습니다.
    - [재고 목록] / [발주 필요] / [발주 기록] / [품목 등록] ··· [저장]
  - 메뉴 버튼을 누르면 그 화면만 보이고 나머지 화면은 숨겨집니다.
  - 지금 보고 있는 화면의 메뉴 버튼은 초록색으로 표시됩니다.
  - 처음 열면 [재고 목록] 화면이 보입니다.
  - 한 화면에서 바꾼 내용(등록, 수량 변경, 수정, 삭제, 발주 완료)은 다른 화면에도 바로 반영됩니다.
  - 재고가 필요 수량보다 적은 품목이 있으면 [발주 필요] 메뉴 버튼 옆에 빨간 동그라미로 개수가 표시됩니다. (예: 발주 필요 ③)
    - 이 숫자는 재고 목록에서 빨간색으로 표시된 품목 개수와 같습니다. 발주 필요 화면에서 품목을 직접 추가하거나 [목록에서 빼기]를 눌러도 숫자는 바뀌지 않습니다.
    - 부족한 품목이 없으면 개수가 표시되지 않습니다.
  - 휴대폰에서는 메뉴 4개가 한 줄에 같은 폭으로 놓이고, [저장] 버튼은 그 아랫줄 오른쪽에 놓입니다.

- **저장**
  - [저장] 버튼을 누르면 지금까지 바꾼 내용(수량 변경, 수정, 삭제)이 브라우저에 저장되고 "저장되었습니다." 안내가 나옵니다.
  - [품목 등록] 화면에서는 [저장] 버튼이 보이지 않습니다. (등록하면 자동으로 저장되기 때문입니다) 버튼 자리는 그대로 남아 메뉴 위치가 흔들리지 않습니다.
  - 품목 등록, 발주 완료, 매장 이름 변경, 드롭다운 목록 변경은 [저장]을 누르지 않아도 자동으로 저장됩니다.
  - 저장한 내용은 새로고침하거나 창을 닫았다 열어도 남아 있습니다.
  - [저장]을 누르지 않고 새로고침하거나 창을 닫으면 마지막으로 저장한 상태로 돌아갑니다.

- **[재고 목록] 화면**: 검색창, 보기 방식 버튼, 재고 목록, 페이지 버튼이 있습니다.
  - 검색창에 품목명을 입력하면 이름에 그 글자가 들어간 품목이 모두 나옵니다. (예: "파" → 대파, 양파)
  - 검색창을 비우면 전체 목록이 다시 나옵니다. 검색 결과가 없으면 "검색 결과가 없습니다." 안내가 나옵니다.
  - [전체 보기] / [거래처별 보기] / [분류별 보기] 중 하나를 누르면 그 기준으로 보여 줍니다.
    - 전체 보기: 품목명 가나다순으로 나옵니다.
    - 거래처별 보기: 거래처 가나다순으로 묶고, 묶음 안에서는 품목명 가나다순입니다.
    - 분류별 보기: 채소 → 육류 → 수산 → 유제품 → 양념 → 공산품 순서로 묶고, 직접 입력한 분류는 그 뒤에 가나다순으로 나옵니다. 묶음 안에서는 품목명 가나다순입니다.
    - 거래처별·분류별 보기에서는 표 맨 왼쪽 칸에 거래처(또는 분류) 이름과 품목 개수가 세로로 합쳐져 나오고, 오른쪽에 그 품목들이 나옵니다. 이때 오른쪽 표에서는 같은 정보가 겹치지 않게 거래처(또는 분류) 칸을 뺍니다.
  - 컴퓨터에서는 재고 목록이 표로 나옵니다. (품목명 / 분류 / 현재 수량 / 수량 변경 [−] [＋] / 필요 수량 / 거래처 / 관리 [수정] [삭제])
  - 휴대폰에서는 품목 하나가 카드 하나로 나옵니다.
    - 카드 왼쪽: 품목명, 현재 수량(크게), 전체 낱개 수, 분류·필요 수량·거래처(작게), [수정] [삭제]
    - 카드 오른쪽: 단위마다 한 줄씩 [−] 수량 [＋]
    - 거래처별·분류별 보기에서는 카드 묶음 위에 거래처(또는 분류) 이름이 제목으로 나옵니다.
  - [−] [＋] 버튼은 "수량 변경" 칸에 따로 놓여서, 수량 글자 길이와 상관없이 같은 세로줄에 나란히 놓입니다.
  - [＋] 버튼을 누르면 수량이 1 늘어나고, [−] 버튼을 누르면 1 줄어듭니다. (물건을 쓰거나 수량이 틀렸을 때 고치는 용도)
  - 묶음 단위를 쓰는 품목은 묶음 수량과 낱개 수량이 각각 한 줄씩 나오고, 줄마다 [−] [＋] 버튼이 같은 높이에 따로 있습니다. (예: 2판 [−][＋] / 5개 [−][＋])
  - 묶음 단위를 쓰는 품목은 전체 낱개 수도 함께 표시됩니다. (예: 총 65개)
  - 수량은 0 아래로 내려가지 않습니다. 묶음 단위를 쓰는 품목은 묶음과 낱개 모두 0 아래로 내려가지 않습니다.
  - [수정] 버튼을 누르면 수정 창이 열리고 다음을 고칠 수 있습니다. 위에는 필요 수량, 아래에는 현재 수량이 있고, 묶음과 낱개는 나란히 놓입니다.
    - 묶음당 낱개 수 (묶음 단위를 쓰는 품목만)
    - 필요 수량 (묶음 단위를 쓰는 품목은 필요 묶음 수량 / 필요 낱개 수량)
    - 현재 수량 (묶음 단위를 쓰는 품목은 현재 묶음 수량 / 현재 낱개 수량)
  - 현재 수량이 필요 수량보다 적으면 그 줄(휴대폰에서는 그 카드)이 연한 빨간색 배경과 왼쪽 빨간 줄로 표시되고, 수량 글자도 빨간색이 됩니다. 묶음 단위를 쓰는 품목은 전체 낱개 수로 비교합니다.
  - [삭제] 버튼을 누르면 "'품목명' 품목을 삭제할까요?" 확인 창이 뜨고, 확인을 누르면 그 품목이 목록에서 사라집니다.
  - **페이지 버튼**: 한 페이지에 품목 10개씩 나옵니다.
    - 페이지 번호는 한 번에 5개까지 보입니다. (1~5, 6~10, 11~15 …) 지금 보고 있는 페이지 번호는 초록색입니다.
    - ‹ › 는 한 페이지씩, « » 는 다섯 페이지씩 이동합니다. 넘어갈 곳이 없으면 마지막(또는 첫) 페이지로 갑니다.
    - 페이지가 1개면 `1`만, 2~5개면 `‹ 1 2 3 ›`, 6개 이상이면 `« ‹ 1 2 3 4 5 › »`가 보입니다.
    - 더 갈 곳이 없는 화살표는 흐리게 보이고 눌리지 않습니다.
    - 검색어를 입력하거나 보기 방식을 바꾸면 1페이지로 돌아갑니다. 품목을 삭제해서 지금 페이지가 비면 앞 페이지로 이동합니다.
    - 거래처별·분류별 보기에서 한 묶음이 두 페이지에 걸치면 다음 페이지에도 묶음 이름이 다시 나오고, 품목 개수는 묶음 전체 개수로 나옵니다.

- **[품목 등록] 화면**: 입력칸들이 3칸씩 줄지어 있고(휴대폰에서는 한 줄에 하나씩), 화면 아래 오른쪽에 [등록] 버튼이 있으며, 안내 문구는 [등록] 버튼 바로 왼쪽에 나옵니다.
  - 칸 순서
    - 첫째 줄: 품목명 / 분류 / 거래처
    - 둘째 줄: 묶음 단위 / 낱개 단위 / 묶음당 낱개 수(묶음 단위를 쓸 때만)
    - 셋째 줄: 필요 수량 (묶음 단위를 쓰면 필요 묶음 수량 / 필요 낱개 수량이 같은 줄에 나란히)
    - 넷째 줄: 현재 수량 (묶음 단위를 쓰면 현재 묶음 수량 / 현재 낱개 수량이 같은 줄에 나란히)
    - 칸 이름에는 고른 단위가 함께 표시됩니다. (예: 필요 묶음 수량 (판), 필요 낱개 수량 (개))
  - 분류, 거래처, 묶음 단위, 낱개 단위는 드롭다운에서 고릅니다.
    - 분류: 채소, 육류, 수산, 유제품, 양념, 공산품, 직접입력 (처음 안내: "분류 선택")
    - 거래처: 이미 등록된 품목의 거래처(가나다순), 직접입력 (처음 안내: "거래처 선택")
    - 묶음 단위: 없음, 박스, 판, 봉지, 팩, 통, 묶음, 직접입력 (처음 값: 없음)
    - 낱개 단위: 개, kg, g, L, 박스, 판, 봉지, 팩, 통, 묶음, 직접입력 (처음 안내: "단위 선택")
    - 예시 품목에 쓰인 단위·분류(롤, 장, 모, 마리, 가공식품 등)도 처음부터 목록에 들어 있습니다.
  - "직접입력"을 고르면 드롭다운 아래에 입력칸이 나타나고, 원하는 이름을 직접 써서 사용할 수 있습니다. 처음에는 입력칸이 보이지 않고, 다른 항목을 고르면 다시 숨겨지며 쓴 글자도 지워집니다.
  - 드롭다운을 열면 각 이름 맨 오른쪽에 작고 연한 × 표시가 있습니다.
    - ×를 누르면 그 이름이 드롭다운 목록에서 삭제됩니다. (이미 등록된 품목은 바뀌지 않습니다)
    - "없음", "직접입력"에는 ×가 없습니다.
    - 삭제한 이름이나 처음 쓰는 이름을 "직접입력"으로 써서 품목을 등록하면 목록에 다시(새로) 추가됩니다.
  - 묶음 단위를 "없음"으로 고르면 묶음당 낱개 수 칸, 필요 묶음 수량 칸, 현재 묶음 수량 칸이 사라지고, 낱개 단위만 사용합니다. (예: 양파 - 낱개 단위 kg)
  - 묶음 단위를 고르면 묶음당 낱개 수를 입력하고, 필요 수량과 현재 수량을 각각 묶음과 낱개로 나눠 입력합니다. 필요 수량은 전체 낱개 수로 저장됩니다. (예: 계란 - 1판 30개, 필요 2판 10개 → 필요 수량 70개)
  - 화면에 보이는 칸을 모두 입력하고 [등록]을 누르면 재고 목록에 품목이 추가되고, 그때까지 바꾼 모든 내용이 자동으로 저장되며, "품목이 등록되고 저장되었습니다." 안내와 함께 [재고 목록] 화면으로 이동합니다.
  - 등록하지 못하면 [등록] 버튼 왼쪽에 빨간 글씨로 안내가 나옵니다.
    - 빈칸이 있을 때: "모든 칸을 입력해 주세요."
    - 묶음당 낱개 수가 0일 때: "묶음당 낱개 수는 1 이상이어야 해요."
    - 같은 품목명이 이미 있을 때: "이미 등록된 품목명입니다."

- **[발주 필요] 화면**: 현재 수량이 필요 수량보다 적은 품목이 자동으로 모여서 나옵니다.
  - 맨 위 왼쪽에 "발주 품목 직접 추가" 검색칸, 오른쪽에 [전체 보기] / [거래처별 보기] / [분류별 보기] 버튼이 있습니다.
  - **직접 추가**: 검색칸을 누르거나 품목명을 입력하면 아직 목록에 없는 품목이 현재 수량·거래처와 함께 나오고, 고르면 발주 목록에 추가됩니다.
  - **목록 순서**: 직접 추가한 품목이 맨 위(가장 최근에 추가한 것부터)에 나오고, 그 아래로 발주가 필요한 품목이 품목명 가나다순으로 나옵니다.
  - **보기 방식**: 거래처별·분류별 보기에서는 재고 목록처럼 왼쪽 칸에 거래처(또는 분류) 이름과 품목 개수가 나오고, 오른쪽에 그 품목들이 나옵니다. (휴대폰에서는 이름이 품목들 위에 제목으로 나옵니다) 묶음 안에서도 직접 추가한 품목이 먼저 나옵니다.
  - **품목 카드 표시**
    - 발주가 필요한 품목: 연한 빨간색 배경과 왼쪽 빨간 줄
    - 직접 추가한 품목(재고가 부족하지 않은 품목): 연한 초록색 배경과 왼쪽 초록 줄, "직접 추가" 표시
  - **품목 카드 구성** (왼쪽부터): 품목명·거래처·현재/필요 수량 → 발주 수량 → 특이사항 → [목록에서 빼기]
    - 카드 안의 모든 칸은 위쪽 기준으로 맞춰집니다.
    - 현재·필요 수량은 묶음 단위를 쓰는 품목이면 두 단위로 나옵니다. (예: 현재 2판 5개 (총 65개) / 필요 3판 0개 (총 90개))
  - **발주 수량**
    - "필요 수량 - 현재 수량"이 자동으로 계산되어 입력칸에 들어갑니다. 묶음 단위를 쓰는 품목은 전체 낱개 수로 계산한 뒤 묶음과 낱개 칸에 나누어 넣습니다. (예: 25개 → 0판 25개)
    - 묶음 단위를 쓰는 품목은 묶음 칸과 낱개 칸이 따로 있고, 그 아래에 "= 총 25개"처럼 전체 낱개 수가 나옵니다.
    - 단위 글자 수가 달라도 입력칸과 단위 글자의 시작 위치가 같게 고정되어 있습니다.
    - 숫자를 직접 고칠 수 있습니다. (예: 25개가 계산되었지만 1판으로 주문) 고친 숫자는 화면을 옮겨도 남아 있고, 그 품목의 재고가 바뀌면 다시 자동 계산됩니다.
    - 직접 추가한 품목은 이미 필요 수량이 채워져 있으므로 발주 수량이 빈칸으로 나옵니다.
  - **특이사항**: 처음에는 연한 글씨 [＋ 특이사항] 버튼만 보입니다. 누르면 입력칸이 열리고(최대 100자), 비워 둔 채 다른 곳을 누르면 다시 버튼으로 돌아갑니다. 꼭 적지 않아도 됩니다.
  - **[목록에서 빼기]**: 모든 품목 카드 맨 오른쪽에 있습니다.
    - 직접 추가한 품목은 목록에서 빠집니다.
    - 발주가 필요한 품목을 빼면 발주 목록에서만 빠지고, 재고 목록의 빨간색 표시는 그대로입니다. 직접 추가 검색으로 다시 넣을 수 있습니다.
  - 재고 목록에서 수량을 바꾸면 발주 필요 목록과 발주 수량도 바로 바뀝니다.
  - 목록이 비어 있으면 "발주가 필요한 품목이 없습니다." 안내가 나옵니다.
  - 목록 아래에 메모 칸(여러 줄, 최대 300자)이 있고, 그 아래에 발주자 이름 칸과 [발주 완료] 버튼이 있습니다. 메모는 꼭 적지 않아도 됩니다.
  - 발주자 이름은 드롭다운에서 고릅니다. (처음 안내: "발주자 선택", 목록: 김민지, 박준호, 직접입력)
    - "직접입력"을 고르면 아래에 입력칸이 나타나고, 새로 입력한 이름은 발주를 완료하면 드롭다운 목록에 추가됩니다.
    - 품목 등록 화면처럼 이름 옆 ×를 누르면 목록에서 지울 수 있습니다.
  - 발주자 이름을 입력하고 [발주 완료]를 누르면 다음이 한 번에 일어납니다.
    1. 발주 수량이 0이거나 빈칸인 품목은 발주에서 빠집니다.
    2. 발주한 품목의 현재 수량에 발주 수량이 더해집니다. 묶음 단위를 쓰는 품목은 묶음 칸의 수는 묶음에, 낱개 칸의 수는 낱개에 더하고, 낱개가 묶음 하나 이상 쌓이면 묶음으로 올려 정리합니다. (예: 1판 30개일 때 2판 25개 + 0판 10개 → 3판 5개)
    3. 현재 수량이 필요 수량 이상이 된 품목은 발주 필요 목록에서 사라지고, 재고 목록의 빨간색 표시도 없어집니다. (발주 수량을 줄여서 여전히 필요 수량보다 적으면 목록에 남습니다)
    4. 발주 기록에 발주 한 건이 추가됩니다. (날짜, 시간, 발주자, 거래처, 품목과 발주 수량, 특이사항, 메모)
    5. 메뉴 버튼의 발주 필요 개수 표시가 바뀝니다. 부족한 품목이 없어지면 개수 표시가 사라집니다.
    6. 직접 추가한 품목, 목록에서 뺀 품목, 특이사항, 메모가 모두 비워지고, 발주자 드롭다운은 "발주자 선택"으로 돌아갑니다.
    7. 그때까지 바꾼 모든 내용이 [저장]을 누르지 않아도 자동으로 저장되고, "발주가 완료되고 재고 및 기록이 저장되었습니다." 안내가 나옵니다.
  - 발주하지 못하면 [발주 완료] 버튼 왼쪽에 빨간 글씨로 안내가 나옵니다.
    - 발주자 이름이 비어 있을 때: "발주자 이름을 입력해 주세요."
    - 모든 발주 수량이 0이거나 빈칸일 때: "발주 수량을 입력해 주세요."

- **[발주 기록] 화면**: 지금까지 완료한 발주가 가장 최근 것부터 나옵니다.
  - 화면에 들어올 때마다 월 선택은 "전체", 페이지는 1페이지로 돌아가고, 가장 최근 발주가 맨 위에 보입니다.
  - 제목 오른쪽 위에 월 선택 드롭다운이 있습니다. "전체"와 발주 기록이 있는 달(예: 2026년 11월)이 최근 달부터 나오고, 고르면 그 달의 기록만 보입니다. 그 달에 기록이 없으면 "선택한 달의 발주 기록이 없습니다." 안내가 나옵니다.
  - 컴퓨터에서는 표로 나옵니다. (발주 날짜 / 발주 시간 / 발주자 / 거래처 / 발주 품목 및 수량 / 특이사항)
    - 발주 날짜에는 요일이 함께 나옵니다. (예: 2026. 11. 11. (수))
    - 품목마다 한 줄씩 나오고, 날짜·시간·발주자는 발주 한 건 전체에, 거래처는 그 거래처의 품목들에 칸이 하나로 합쳐져 있습니다.
    - 품목 칸에는 "계란 · 35개 (1판 5개)"처럼 발주 수량이 나오고, 특이사항은 맨 오른쪽 칸에 시작선을 맞춰 나옵니다.
    - 발주 한 건의 맨 아래에 표 전체 폭으로 메모 줄이 있습니다. 메모가 없으면 연한 글씨로 "메모 없음"이 나옵니다.
    - 발주 한 건마다 테두리로 묶이고(위·아래 테두리는 조금 더 진하고 두껍게), 건과 건 사이는 띄워져 있으며, 각 건의 위쪽에 여백이 있습니다.
    - 가장 최근 발주 한 건에만 연한 초록색 배경이 들어가고, 나머지는 흰색입니다.
  - 휴대폰에서는 발주 한 건이 카드 하나로 나옵니다. (발주자, 날짜(요일)·시간, 거래처별 품목과 특이사항, 맨 아래 메모)
  - 날짜와 시간은 [발주 완료]를 누른 순간의 컴퓨터(또는 휴대폰) 시간으로 자동 입력됩니다.
  - 한 페이지에 발주 10건씩 나오고, 페이지 버튼 규칙은 재고 목록과 같습니다. 달을 바꾸면 1페이지로 돌아갑니다.
  - 아직 발주한 적이 없으면 "발주 기록이 없습니다." 안내가 나옵니다.

## 완료 기준
- 메뉴 버튼을 누르면 해당 화면만 보이고, 다른 화면에서 바꾼 내용이 그대로 반영되어 있습니다.
- 처음 열었을 때 [재고 목록] 화면이 보입니다.
- 제목 아랫줄 오른쪽에 메뉴 4개(재고 목록 / 발주 필요 / 발주 기록 / 품목 등록)와 [저장] 버튼이 있고, 메뉴와 [저장] 사이가 메뉴끼리의 간격보다 넓습니다.
- [저장] 버튼은 회색이고, [품목 등록] 화면에서는 보이지 않습니다.
- 제목의 "매장"을 눌러 이름을 바꾸면 제목과 브라우저 탭 제목이 바뀌고, 새로고침해도 남아 있습니다.
- 재고 목록 전체 보기에서 품목이 품목명 가나다순으로 나옵니다.
- [거래처별 보기]와 [분류별 보기]를 누르면 표 맨 왼쪽 칸에 거래처(분류) 이름이 나오고, 오른쪽에 그 품목들이 묶여 나옵니다.
- 재고 목록과 발주 기록에서 한 페이지에 10개(건)씩 나오고, 페이지 수에 따라 페이지 버튼이 정해진 규칙대로 보입니다.
- 품목명, 분류, 거래처, 단위, 필요 수량, 현재 수량을 입력하고 [등록]을 누르면 재고 목록에 새 품목이 추가됩니다.
- [등록] 후 [저장]을 누르지 않고 새로고침해도 등록한 품목이 남아 있습니다.
- 빈칸이 있는 상태로 [등록]을 누르면 품목이 추가되지 않고, [등록] 버튼 왼쪽에 안내 문구가 나옵니다.
- 묶음 단위를 "없음"으로 고르면 묶음당 낱개 수 칸과 묶음 수량 칸들이 사라지고, 필요 수량 아랫줄에 현재 수량이 나옵니다.
- 묶음 단위를 고르면 필요 묶음·낱개 수량이 한 줄에, 그 아랫줄에 현재 묶음·낱개 수량이 한 줄에 나옵니다.
- 분류나 단위, 거래처에서 "직접입력"을 고르면 입력칸이 나타나고, 입력한 이름이 재고 목록에 그대로 표시되며 다음부터 드롭다운에 나옵니다.
- 드롭다운 안의 이름 옆 ×를 누르면 그 이름이 드롭다운 목록에서 사라집니다.
- 수량 입력칸에 숫자 외의 글자가 들어가지 않고, 앞자리 0이 자동으로 지워집니다.
- [−] / [＋] 버튼은 "수량 변경" 칸에서 모든 줄이 같은 세로줄에 있습니다.
- [−] / [＋] 버튼을 누르면 해당 품목의 수량이 1씩 바뀌고, 0 아래로 내려가지 않습니다.
- 묶음 단위를 쓰는 품목은 묶음과 낱개마다 [−] / [＋]로 수량이 따로 바뀌고, 전체 낱개 수가 "묶음 수량 × 묶음당 낱개 수 + 낱개 수량"과 같습니다.
- [수정]으로 필요 수량, 현재 수량, 묶음당 낱개 수를 바꾸면 발주 수량과 전체 낱개 수에 바로 반영됩니다.
- 현재 수량이 필요 수량보다 적어지면 그 품목이 빨간색으로 바뀌고 발주 필요 목록에 나타납니다.
- [발주 필요] 메뉴 버튼 옆 숫자가 재고 목록에서 빨간색으로 표시된 품목 개수와 같습니다.
- 발주 필요 목록의 발주 수량이 "필요 수량 - 현재 수량"과 같습니다. (묶음 단위 품목은 묶음 칸 × 묶음당 낱개 수 + 낱개 칸)
- 발주 필요 목록에서 발주가 필요한 품목은 왼쪽 빨간 줄, 직접 추가한 품목은 초록색으로 표시되고, 직접 추가한 품목이 맨 위에 나옵니다.
- [목록에서 빼기]를 누르면 그 품목이 발주 목록에서 빠지고, 직접 추가 검색으로 다시 넣을 수 있습니다.
- 발주 수량을 직접 고친 뒤 [발주 완료]를 누르면 고친 숫자만큼 재고 수량에 더해집니다.
- 발주자 이름을 입력하고 [발주 완료]를 누르면 재고 수량에 발주 수량이 더해지고, 필요 수량 이상이 된 품목은 발주 필요 목록에서 사라집니다.
- 발주자 이름 없이 [발주 완료]를 누르면 발주가 되지 않고 안내 문구가 나옵니다.
- [발주 완료] 후 발주 기록에 날짜(요일), 시간, 발주자, 거래처, 품목과 발주 수량, 특이사항, 메모가 나옵니다.
- 발주 기록에 들어가면 가장 최근 발주가 맨 위에 있고, 월 선택으로 그 달의 기록만 볼 수 있습니다.
- [저장]을 누른 뒤 새로고침해도 수량 변경, 수정, 삭제한 내용이 그대로 남아 있습니다.
- [저장]을 누르지 않고 새로고침하면 마지막으로 저장한 상태로 돌아갑니다.
- [발주 완료] 후 [저장]을 누르지 않고 새로고침해도 발주 결과와 발주 기록이 남아 있습니다.
- 검색창에 품목명 일부를 입력하면 그 글자가 들어간 품목이 모두 나옵니다.
- [삭제]를 누르고 확인하면 재고 목록과 발주 필요 목록에서 모두 사라집니다.
- 휴대폰 폭(약 360px)에서 재고 목록·발주 기록이 카드 형태로 바뀌고, 글자가 겹치거나 화면 밖으로 나가지 않습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.


## 필수 기능
- 메뉴 4개로 화면 전환, 발주 필요 개수 표시, 매장 이름 바꾸기
- 재고 목록 보기(가나다순), 검색, 거래처별·분류별 보기(왼쪽 칸 묶음), 페이지 버튼
- [−] [＋]로 수량 바꾸기 (묶음 단위 품목은 묶음과 낱개 따로), [삭제]
- [수정]으로 필요 수량, 현재 수량, 묶음당 낱개 수 고치기
- 품목 등록 (드롭다운으로 분류·거래처·단위 선택, 직접입력, 드롭다운 목록에서 × 삭제, 빈칸이 있으면 등록 안 됨, 등록 시 자동 저장)
- 숫자만 입력되는 수량 칸 (앞자리 0 자동 삭제)
- 발주 필요 목록 자동 표시, 직접 추가와 목록에서 빼기, 보기 방식, 발주 수량 자동 계산과 직접 수정, 품목별 특이사항, 메모
- 발주 완료 (재고 수량에 반영, 기록 남기기, 자동 저장)
- 발주 기록 보기 (요일 표시, 거래처·특이사항·메모, 월 선택, 페이지 버튼)
- [저장] 버튼으로 브라우저에 저장하기
- 컴퓨터와 휴대폰 화면 크기에 맞춰 보이기 (휴대폰에서는 카드 형태)


## 추가 기능
- 발주 필요 목록을 복사 버튼 하나로 복사해서 거래처에 문자로 보내기 쉽게 만들기
- 수량을 1씩이 아니라 원하는 숫자만큼 한 번에 더하거나 빼기 (지금은 [수정] 창에서 현재 수량을 직접 바꾸는 방식만 있습니다)
- 거래처별로 따로 [발주 완료] 하기
- 품목별로 얼마나 나갔는지 하루·일주일·월·년·요일별로 보기 (기본 기능이 자리 잡은 뒤 추가)


## 한계 및 비목표
1. 거래처에 실제로 주문을 보내지는 않습니다. 발주가 필요한 품목과 수량을 보여 주고 기록만 남깁니다.
2. [발주 완료]를 누르는 순간 물건이 들어온 것으로 보고 수량을 바꿉니다. 실제 배송 날짜나 배송이 빠진 경우는 반영하지 않습니다.
3. 로그인, 여러 사람이 함께 쓰는 기능, 서버 저장은 이번 범위에서 제외합니다. 발주자는 이름을 직접 입력하는 방식입니다. 저장은 지금 쓰는 기기의 브라우저에만 되므로, 다른 컴퓨터나 휴대폰에서는 같은 내용을 볼 수 없습니다.
4. 가격 계산, 유통기한 관리, 매출과 연결한 자동 발주 예측은 하지 않습니다.
5. 이미 완료한 발주 기록은 고치거나 지울 수 없습니다.
6. 발주 목록에서 직접 추가한 품목, 뺀 품목, 아직 [발주 완료]하지 않은 특이사항과 메모는 저장되지 않아서, 새로고침하면 사라집니다.
7. 드롭다운 목록에서 이름을 지워도 그 이름을 쓰는 품목은 그대로 남아 있습니다.


## 검증 방법
- [발주 필요] 화면에 나온 품목마다 재고 목록의 필요 수량과 현재 수량을 종이에 적고(묶음 단위 품목은 전체 낱개 수로 직접 계산), 손으로 계산한 "필요 수량 - 현재 수량"을 화면의 발주 수량(묶음 칸 × 묶음당 낱개 수 + 낱개 칸)과 비교합니다.
- 그다음 몇 개 품목의 발주 수량을 직접 고치고, 재고가 충분한 품목 하나를 직접 추가한 뒤 [발주 완료]를 누릅니다. "발주 전 수량 + 발주 수량"이 재고 목록의 새 수량과 같은지 비교합니다.
- [발주 기록]에서 방금 한 발주가 맨 위에 있고, 거래처·품목·수량·특이사항·메모가 입력한 대로 나오는지 확인합니다.
- 브라우저 창 폭을 360px 정도로 줄여서 재고 목록, 발주 필요, 발주 기록 화면이 카드 형태로 바뀌고 글자가 겹치지 않는지 확인합니다.

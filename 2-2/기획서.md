# 식재료 발주 관리 페이지

## 대상 사용자
- 소규모 식당에서 재고를 확인하고 식재료 발주를 맡는 주방 담당자 (사장, 점장, 주방 직원)
- 컴퓨터와 휴대폰 중 편한 기기로 사용합니다.


## 사용 목적
- 가게에 있는 식재료와 공산품(휴지, 물티슈 등)의 남은 수량을 한눈에 확인합니다.
- 발주 전에 품목의 남은 수량을 확인하고 수정합니다.
- 수량이 부족한 품목을 "발주 필요 목록"으로 자동으로 모아 보여 줘서 주문을 빠뜨리지 않게 합니다.
- 발주를 완료하면 재고 수량이 자동으로 바뀌어서, 물건이 들어올 때마다 따로 고치지 않아도 됩니다.
- 누가, 언제 발주했는지 기록으로 남깁니다.


## 화면 구성과 동작
- **용어**
  - 품목: 관리하는 물건 하나하나입니다. 식재료와 공산품을 모두 포함합니다. (예: 양파, 계란, 물티슈)
  - 분류: 품목을 묶는 종류입니다. (예: 채소, 육류, 공산품)
  - 묶음 단위 / 낱개 단위: 수량을 세는 단위입니다. 묶음 단위는 쓰지 않을 수도 있습니다. (예: 계란 - 묶음 단위 "판", 낱개 단위 "개")
  - 묶음당 낱개 수: 묶음 하나에 들어 있는 낱개의 수입니다. (예: 1판 = 30개)
  - 필요 수량: 현재 수량이 이 값보다 적어지면 발주가 필요하다고 봅니다. 발주하면 이 수량만큼 채워집니다. 품목마다 정하고 고칠 수 있습니다.
  - 발주 수량: 이번에 주문할 양입니다. "필요 수량 - 현재 수량"으로 자동 계산되고, 직접 고칠 수 있습니다.

- **공통**: 컴퓨터와 휴대폰 화면 크기에 맞춰 보입니다. 휴대폰에서도 글자가 겹치거나 화면 밖으로 나가지 않고, 버튼은 손가락으로 누르기 쉬운 크기로 보입니다.

- **공통 메뉴**: 화면 맨 위 왼쪽에 페이지 제목 "식재료 발주 관리"와 메뉴 버튼 4개가 있고, 오른쪽 끝에 회색 [저장] 버튼이 메뉴와 떨어져 있습니다. [재고 목록] / [품목 등록] / [발주 필요] / [발주 기록] ··· [저장]
  - 메뉴 버튼을 누르면 그 화면만 보이고 나머지 화면은 숨겨집니다.
  - 지금 보고 있는 화면의 메뉴 버튼은 색이 다르게 표시됩니다.
  - 처음 열면 [재고 목록] 화면이 보입니다.
  - 한 화면에서 바꾼 내용(등록, 수량 변경, 수정, 삭제, 발주 완료)은 다른 화면에도 바로 반영됩니다.
  - 발주가 필요한 품목이 있으면 [발주 필요] 메뉴 버튼에 개수가 표시됩니다. (예: 발주 필요 (3))
  - 발주가 필요한 품목이 없으면 개수가 표시되지 않습니다.
  - [저장] 버튼을 누르면 지금까지 바꾼 내용(수량 변경, 수정, 삭제)이 브라우저에 저장되고 "저장되었습니다" 안내가 나옵니다.
  - [품목 등록] 화면에서는 [저장] 버튼이 보이지 않습니다. (등록하면 자동으로 저장되기 때문입니다)
  - 저장한 내용은 새로고침하거나 창을 닫았다 열어도 남아 있습니다.
  - [저장]을 누르지 않고 새로고침하거나 창을 닫으면 마지막으로 저장한 상태로 돌아갑니다.

- **[재고 목록] 화면**: 검색창, 보기 방식 버튼, 재고 목록이 있습니다.
  - 검색창에 품목 이름을 입력하면 이름에 그 글자가 들어간 품목이 모두 나옵니다. (예: "파" → 양파, 대파, 쪽파)
  - 검색창을 비우면 전체 목록이 다시 나옵니다.
  - [전체 보기] / [거래처별 보기] / [분류별 보기] 중 하나를 누르면 그 기준으로 묶어서 보여 줍니다.
  - 컴퓨터에서는 재고 목록이 표로 나옵니다. (품목 이름 / 분류 / 현재 수량 / 필요 수량 / 거래처 / 수량 변경 [+] [-] / [수정] [삭제])
  - 휴대폰에서는 품목 하나가 카드 하나로 나옵니다. 카드 왼쪽에 품목 이름과 현재 수량이 크게 보이고, 그 아래에 분류·필요 수량·거래처가 작게 보이며, [+] [-]는 카드 오른쪽에 놓입니다.
  - [+] [-] 버튼은 수량 글자 길이와 상관없이 오른쪽의 같은 세로줄에 나란히 놓입니다.
  - [+] 버튼을 누르면 수량이 1 늘어나고, [-] 버튼을 누르면 1 줄어듭니다. (물건을 쓰거나 수량이 틀렸을 때 고치는 용도)
  - 묶음 단위를 쓰는 품목은 묶음 수량과 낱개 수량이 각각 한 줄씩 나오고, 줄마다 [+] [-] 버튼이 따로 있습니다. (예: 계란 2판 [+] [-] / 5개 [+] [-])
  - 묶음 단위를 쓰는 품목은 전체 낱개 수도 함께 표시됩니다. 전체 낱개 수 = 묶음 수량 × 묶음당 낱개 수 + 낱개 수량 (예: 1판 30개일 때 2판 5개 → 총 65개)
  - 수량은 0 아래로 내려가지 않습니다. 묶음 단위를 쓰는 품목은 묶음과 낱개 모두 0 아래로 내려가지 않습니다.
  - [수정] 버튼을 누르면 그 품목의 필요 수량과 묶음당 낱개 수를 고칠 수 있습니다.
  - 현재 수량이 필요 수량보다 적으면 그 줄(휴대폰에서는 그 카드)이 빨간색으로 표시됩니다. 묶음 단위를 쓰는 품목은 전체 낱개 수로 비교합니다.
  - [삭제] 버튼을 누르면 그 품목이 목록에서 사라집니다.

- **[품목 등록] 화면**: 품목 이름, 분류, 묶음 단위, 낱개 단위, 묶음당 낱개 수, 현재 수량, 필요 수량, 거래처를 입력하는 칸이 있습니다. 화면 아래 오른쪽에 [등록] 버튼이 있고, 안내 문구는 [등록] 버튼 바로 왼쪽에 나옵니다.
  - 분류는 드롭다운에서 고릅니다. (채소, 육류, 수산, 유제품, 양념, 공산품, 기타)
  - 묶음 단위는 드롭다운에서 고릅니다. (없음, 박스, 판, 봉지, 팩, 통, 묶음, 직접입력)
  - 낱개 단위는 드롭다운에서 고릅니다. (개, kg, g, L, 박스, 판, 봉지, 팩, 통, 묶음, 직접입력)
  - 단위에서 "직접입력"을 고르면 옆에 입력칸이 나타나고, 원하는 단위를 직접 써서 사용할 수 있습니다.
  - 묶음 단위를 "없음"으로 고르면 묶음당 낱개 수 칸과 묶음 수량 칸이 사라지고, 낱개 단위만 사용합니다. (예: 양파 - 낱개 단위 kg)
  - 묶음 단위를 고르면 묶음 수량과 낱개 수량을 각각 입력하고, 묶음당 낱개 수를 함께 입력합니다.
  - 묶음 단위를 쓰는 품목의 필요 수량은 낱개 단위 기준으로 입력합니다. (예: 계란 - 1판 30개, 필요 수량 90개)
  - 화면에 보이는 칸을 모두 입력하고 [등록]을 누르면 "등록되었습니다" 안내가 나오고, 재고 목록에 품목이 한 줄 추가되며, 그때까지 바꾼 모든 내용이 자동으로 저장됩니다.
  - 빈칸이 있으면 등록되지 않고 "모든 칸을 입력해 주세요" 안내가 나옵니다.

- **[발주 필요] 화면**: 현재 수량이 필요 수량보다 적은 품목만 따로 모여서 나옵니다.
  - 각 품목마다 "발주 수량 = 필요 수량 - 현재 수량"이 자동으로 계산되어 표시됩니다. 묶음 단위를 쓰는 품목은 전체 낱개 수로 계산합니다.
  - 발주 수량은 숫자를 직접 고칠 수 있습니다. (예: 25개가 계산되었지만 1판(30개) 단위로 주문)
  - 재고 목록에서 수량을 바꾸면 발주 필요 목록과 발주 수량도 바로 바뀝니다.
  - 발주할 품목이 없으면 "발주가 필요한 품목이 없습니다" 안내가 나옵니다.
  - 발주자 이름을 입력하는 칸과 [발주 완료] 버튼이 있습니다.
  - 발주자 이름을 입력하고 [발주 완료]를 누르면 다음이 한 번에 일어납니다.
    1. 발주한 품목의 현재 수량에 발주 수량이 더해집니다. 묶음 단위를 쓰는 품목은 묶음당 낱개 수로 나눠 묶음과 낱개에 나누어 더합니다. (예: 1판 30개일 때 65개 → 2판 5개)
    2. 현재 수량이 필요 수량 이상이 된 품목은 발주 필요 목록에서 사라지고, 재고 목록의 빨간색 표시도 없어집니다. (발주 수량을 줄여서 여전히 필요 수량보다 적으면 목록에 남습니다)
    3. 발주 기록에 한 줄이 추가됩니다.
    4. 메뉴 버튼의 발주 필요 개수 표시가 바뀝니다. 발주 필요 목록이 비면 개수 표시가 사라집니다.
    5. 그때까지 바꾼 모든 내용이 [저장]을 누르지 않아도 자동으로 저장됩니다.
  - 발주자 이름이 비어 있으면 발주가 완료되지 않고 "발주자 이름을 입력해 주세요" 안내가 나옵니다.

- **[발주 기록] 화면**: 지금까지 완료한 발주가 최근 것부터 나옵니다. (발주 날짜 / 발주 시간 / 발주자 / 발주한 품목과 발주 수량)
  - 날짜와 시간은 [발주 완료]를 누른 순간의 컴퓨터(또는 휴대폰) 시간으로 자동 입력됩니다.
  - 아직 발주한 적이 없으면 "발주 기록이 없습니다" 안내가 나옵니다.


## 필요한 자료
- 처음 화면에 보여 줄 예시 품목 5~10개 (예: 양파, 대파, 돼지고기, 계란, 식용유, 휴지, 물티슈 등)
- 품목별 분류, 단위, 필요 수량 예시 (실제 식당에서 일했던 경험을 바탕으로 정합니다)
- 묶음 단위를 쓰는 품목 예시 1~2개와 묶음당 낱개 수 (예: 계란 1판 30개)
- 예시 거래처 이름 2~3개 (예: ○○채소, △△정육)
- 예시 발주자 이름 1~2개


## 완료 기준
(페이지의 완료 여부를 판단할 조건을 작성합니다)

- 메뉴 버튼을 누르면 해당 화면만 보이고, 다른 화면에서 바꾼 내용이 그대로 반영되어 있습니다.
- 처음 열었을 때 [재고 목록] 화면이 보입니다.
- [저장] 버튼은 회색이고, 메뉴 버튼들과 떨어진 오른쪽 끝에 있으며, [품목 등록] 화면에서는 보이지 않습니다.
- 품목 이름, 분류, 단위, 수량, 필요 수량, 거래처를 입력하고 [등록]을 누르면 재고 목록에 새 품목이 추가됩니다.
- [등록] 후 [저장]을 누르지 않고 새로고침해도 등록한 품목이 남아 있습니다.
- 빈칸이 있는 상태로 [등록]을 누르면 품목이 추가되지 않고, [등록] 버튼 왼쪽에 안내 문구가 나옵니다.
- 묶음 단위를 "없음"으로 고르면 묶음당 낱개 수 칸과 묶음 수량 칸이 사라집니다.
- 단위에서 "직접입력"을 고르면 입력칸이 나타나고, 입력한 단위가 재고 목록에 그대로 표시됩니다.
- [+] / [-] 버튼은 모든 줄에서 같은 세로줄에 있습니다.
- [+] / [-] 버튼을 누르면 해당 품목의 수량이 1씩 바뀌고, 0 아래로 내려가지 않습니다.
- 묶음 단위를 쓰는 품목은 묶음과 낱개마다 [+] / [-]로 수량이 따로 바뀌고, 전체 낱개 수가 "묶음 수량 × 묶음당 낱개 수 + 낱개 수량"과 같습니다.
- [수정]으로 필요 수량이나 묶음당 낱개 수를 바꾸면 발주 수량과 전체 낱개 수에 바로 반영됩니다.
- 현재 수량이 필요 수량보다 적어지면 그 품목이 빨간색으로 바뀌고 발주 필요 목록에 나타납니다.
- [발주 필요] 메뉴 버튼에 표시된 개수가 발주 필요 목록에 있는 품목 개수와 같습니다.
- 발주 필요 목록의 발주 수량이 "필요 수량 - 현재 수량"과 같습니다.
- 발주 수량을 직접 고친 뒤 [발주 완료]를 누르면 고친 숫자만큼 재고 수량에 더해집니다.
- 발주자 이름을 입력하고 [발주 완료]를 누르면 재고 수량에 발주 수량이 더해지고, 필요 수량 이상이 된 품목은 발주 필요 목록에서 사라집니다.
- 발주자 이름 없이 [발주 완료]를 누르면 발주가 되지 않고 안내 문구가 나옵니다.
- [발주 완료] 후 발주 기록에 날짜, 시간, 발주자, 품목과 발주 수량이 나옵니다.
- [저장]을 누른 뒤 새로고침해도 수량 변경, 수정, 삭제한 내용이 그대로 남아 있습니다.
- [저장]을 누르지 않고 새로고침하면 마지막으로 저장한 상태로 돌아갑니다.
- [발주 완료] 후 [저장]을 누르지 않고 새로고침해도 발주 결과와 발주 기록이 남아 있습니다.
- 검색창에 품목 이름 일부를 입력하면 그 글자가 들어간 품목이 모두 나옵니다.
- [거래처별 보기]와 [분류별 보기]를 누르면 품목이 각각 거래처와 분류 기준으로 묶여 나옵니다.
- [삭제]를 누르면 재고 목록과 발주 필요 목록에서 모두 사라집니다.
- 휴대폰 폭(약 360px)에서 재고 목록이 카드 형태로 바뀌고, 글자가 겹치거나 화면 밖으로 나가지 않습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.


## 필수 기능
- 메뉴 4개로 화면 전환, 발주 필요 개수 표시
- 재고 목록 보기, 검색, 거래처별·분류별 보기
- [+] [-]로 수량 바꾸기 (묶음 단위 품목은 묶음과 낱개 따로), [삭제]
- [수정]으로 필요 수량과 묶음당 낱개 수 고치기
- 품목 등록 (드롭다운으로 분류·단위 선택, 직접입력 단위, 빈칸이 있으면 등록 안 됨, 등록 시 자동 저장)
- 발주 필요 목록 자동 표시, 발주 수량 자동 계산과 직접 수정
- 발주 완료 (재고 수량에 반영, 기록 남기기, 자동 저장)
- 발주 기록 보기
- [저장] 버튼으로 브라우저에 저장하기
- 컴퓨터와 휴대폰 화면 크기에 맞춰 보이기 (휴대폰에서는 카드 형태)


## 추가 기능
- 발주 필요 목록을 복사 버튼 하나로 복사해서 거래처에 문자로 보내기 쉽게 만들기
- 수량을 1씩이 아니라 원하는 숫자만큼 한 번에 바꾸기
- 거래처별로 따로 [발주 완료] 하기
- 품목별로 얼마나 나갔는지 하루·일주일·월·년·요일별로 보기 (기본 기능이 자리 잡은 뒤 추가)


## 한계 및 비목표
(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

1. 거래처에 실제로 주문을 보내지는 않습니다. 발주가 필요한 품목과 수량을 보여 주고 기록만 남깁니다.
2. [발주 완료]를 누르는 순간 물건이 들어온 것으로 보고 수량을 바꿉니다. 실제 배송 날짜나 배송이 빠진 경우는 반영하지 않습니다.
3. 로그인, 여러 사람이 함께 쓰는 기능, 서버 저장은 이번 범위에서 제외합니다. 발주자는 이름을 직접 입력하는 방식입니다. 저장은 지금 쓰는 기기의 브라우저에만 되므로, 다른 컴퓨터나 휴대폰에서는 같은 내용을 볼 수 없습니다.
4. 가격 계산, 유통기한 관리, 매출과 연결한 자동 발주 예측은 하지 않습니다.


## 검증 방법
(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

- [발주 필요] 화면에 나온 품목마다 재고 목록의 필요 수량과 현재 수량을 종이에 적고(묶음 단위 품목은 전체 낱개 수로 직접 계산), 손으로 계산한 "필요 수량 - 현재 수량"을 화면의 발주 수량과 비교합니다. 그다음 [발주 완료]를 누르고, "발주 전 수량 + 발주 수량"이 재고 목록의 새 수량과 같은지 비교합니다.
